# 句外输入法 0.3.0 · 完整离线测试版

这是 InputMethodKit 输入法，不再是独立编辑器。

- 句外拼音 / 句外英文，直接在当前输入框使用。
- 中文整句翻译、英文整句改写、中文讲解，口语 / 学术二选一。
- 自带 Rime 引擎、Luna Pinyin 词典、llama.cpp 和 Qwen2.5-1.5B Q4_K_M 模型；下载后可断网运行，无需 API Key 或 Ollama。
- 英文作为原生输入法候选展示；不会混进宿主 marked text，Return 默认提交原文。英文输出模式可以 Tab 明确采用。
- 专用安装器安装到当前用户的输入法目录，注册两个系统输入模式。

面向 Apple Silicon / macOS26+，优先目标 M5、16GB、13英寸 MacBook Air。

当前不是通用框内灰字实现。实际百度搜索框、已登录微信聊天框尚需实机验收；CI 标准控件测试不能代替。请先以非重要文本试用。

安装包较大（含约1.1GB模型），尚未 Apple Developer ID 签名或公证。系统可能要求在“隐私与安全性”中确认打开。无需关闭安全保护。
