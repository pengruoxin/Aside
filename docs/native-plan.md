# 原生 Mac 开发计划

用户确认：保留苹果拼音和系统英文输入，原生常用工具；中文翻译，英文改写，两者附中文讲解。当前 Windows 无 Swift/Xcode，不宣称 Mac 构建通过。

## 范围与取舍

Swift Package、SwiftUI 原生菜单栏和设置；本地 Ollama 服务生成真实结果。首版只接本机服务，不发送到公网，不包含账号或计费。网页仅作设计归档。

跨应用通过辅助功能读取明确选区；自动模式需用户单独启用，仅读取当前可编辑、非安全、支持的标准文本控件。无法判断或读取就停止。默认手动。不接管键盘，不改输入源，不向其他应用强插灰字。

原生自有练习编辑区提供真正的框内灰字；跨应用结果通过用户打开的菜单栏窗口查看。不能把这项退路描述成所有应用都支持框内灰字。

## 任务

- [ ] Foundation 核心与单元测试：完整内容句末触发、语言判断、提示词约束、结果校验。
- [ ] 原生菜单栏、设置、中文/英文练习编辑区、讲解、复制与内部确认替换。
- [ ] 本机翻译服务、取消和旧结果隔离、明确权限提示、跨应用手动选区与可关闭自动检测。
- [ ] 构建脚本、macOS CI 和人工兼容性清单。

## 验证

Mac: swift test；swift build -c release；构建 app。人工测试苹果拼音候选、ABC、Caps Lock/系统切换、组合输入、富文本、多屏、焦点变化、权限撤销、断网、过期响应。

Windows: 检查文件结构、diff、脚本和 plist 等；无法运行 Swift 单元测试。测试代码先于实现加入，但 RED/GREEN 需 Mac 执行，尚无结果。

## 兼容策略

macOS 13+，Intel 与 Apple Silicon 分别构建。不覆盖输入法或全局快捷键。首版外部替换暂不开放，仅复制；避免未经实测的范围写入破坏正文。自动读取无法可靠判断所有应用的拼音组合态，因此仅作为实验选项且默认关闭。
