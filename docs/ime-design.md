# 句外真实输入法 · 0.3 设计

用户确认：不再独立编辑器；真正输入源；重点百度搜索框与微信聊天框；中文翻译、英文改写都离线；苹果式操作。目标设备为 13 英寸 MacBook Air，M5，16GB，macOS 26.5.1。

## 路线

InputMethodKit 原生输入源，提供句外拼音 / 句外英文两个系统模式。中文使用 BSD librime 与 LGPL Luna Pinyin 字典；自行实现 Swift 前端，不复制 GPL Squirrel 实现。候选词由 IMKCandidates 显示。英文采用同一输入源的英文模式。系统输入源切换由 macOS 管理，不以 Shift 单键切换。

重要实现取舍：不向宿主 marked text 混入翻译英文，以免被网页或聊天软件误读为正文。默认在原生输入法候选区显示整句英文，不是独立翻译卡片。通用框内灰字不宣称已实现。

## 组成与操作

拼音未确认内容和已选中文词语分开存放。拼音空格/数字选词，词语累积为一句；句末才触发翻译。无标点搜索内容可用输入法菜单或仅句外激活时的 Control+Option+T 主动处理。英文模式同理。单个词默认不自动翻译。

选好的词立即写入宿主，只有尚未确认的拼音处于 marked text。整句上下文在后台累积，不把已确认中文长期留作组合输入。异步模型结果只更新候选区，不重新写入正文。Return 不重复插入已确认原文；删除、撤销和光标移动由宿主处理。普通退格在核对原文后预测删除一个字素，下一次事件重新核对；其他编辑或核对不一致时清除学习上下文。

Tab 采用英文时检查当前会话、client 标识、UTF-16 范围、折叠光标位置、无活动 marked text，以及宿主原文完全相等。无法读取或核对的输入框只保留原文；绝不回退为在未知位置插入旧英文。用户换焦点、发送或编辑后，旧请求失效。

Return 有拼音时只确认组合输入；无拼音时提交原文并交给宿主处理搜索/发送。候选英文从不自动发送；英文输出模式可 Tab 或点英文候选采用，下一次 Return 由宿主处理。学习模式点英文候选查看讲解。Esc 先取消拼音/隐藏学习提示；光标移动、命令快捷键、焦点变化前只提交原文并使旧响应失效。

所有输入与提示都围绕宿主 client。输入法设置只有风格、学习/英文输出、自动提示、暂停、离线模型状态，无自由输入编辑区、云端 API 或密钥设置。

## 离线引擎

默认使用包内模型。设置中可选择 FoundationModels 本机系统模型；运行时检查可用性，不假设 Apple Intelligence 已启用或地区可用。完整离线安装包带 llama.cpp 静态推理程序与 Qwen2.5-1.5B-Instruct Q4_K_M GGUF（1117320736 字节，SHA256 6a1a2eb6d15622bf3c96857206351ba97e1af16c30d7a74ee38970e434e9407e）。苹果本机模型不可用时可在设置中切回包内模型。设备无需安装 Ollama、Homebrew 或输入 API Key。推理只绑定 loopback 随机端口并使用临时随机令牌，不向远程发送输入内容。

构建期下载第三方源与模型并核对哈希，附相应许可证。用户下载完整安装包后可断网使用。首次测试小模型的表达质量与速度，不将结构化返回当作准确性证明。

## 安装

专用原生安装器复制输入法至当前用户 ~/Library/Input Methods/Aside.app，通过 TIS 注册/启用两个输入模式。不会再以拖入 Applications 的普通编辑器冒充输入法。保留旧版用户数据，升级只替换本输入法包。无开发者证书时明确未公证。
