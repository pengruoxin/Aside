# 句外 Aside 0.2.0 · 原生 Mac 预览版

中文照常写，英文顺手学。

- 原生菜单栏、偏好设置、首次配置引导与应用图标。
- 沿用苹果拼音和 ABC，不拦截系统输入源切换键。
- 中文翻译 / 英文改写；口语或学术二选一；中文讲解和手动收藏。
- 本机 Ollama 或 HTTPS Chat Completions 兼容接口；云端密钥保存在钥匙串中。
- 系统服务处理选中文字；原生句外编辑区展示框内浅灰英文。
- Intel 与 Apple Silicon 分别构建，DMG 拖入 Applications 安装。

## 下载与开始

Apple Silicon（M 系列）选择 arm64；Intel 选择 x86_64。打开 DMG，将 Aside 拖入 Applications，再从 Applications 打开。菜单栏出现“句外”即已运行。

首次运行需配置自己的翻译服务：启动 Ollama 并选择已安装模型，或填写云端 API 地址、模型和自己的 API Key。此包不包含模型或免费额度。

## 预览版边界

尚未使用 Apple Developer ID 签名和公证。系统可能阻止首次打开；核对本仓库发布来源后，可在系统设置 → 隐私与安全性中使用“仍要打开”。不要关闭系统安全保护。

第三方应用暂不支持通用框内灰字；使用选区服务 / 菜单栏结果。自动读取仅备忘录与文本编辑的实验功能，默认关闭。CI 编译、测试与原生启动检查不替代用户真实 Mac 的输入法和第三方应用验收。
