# 句外 Aside

**中文照常写，英文顺手学。**

原生 macOS 英语学习助手。保留苹果自带拼音和 ABC，不自行实现拼音、不改系统输入源切换、不套用 Windows 按键规则。

> 当前是原生客户端的早期源码版，尚未在 Mac 上构建或实机验收。Windows 开发环境不能验证 AppKit、输入组合态、权限和跨应用行为；不要把网页原型当成已完成的 Mac 输入法。

## 中文与英文

- 中文 → 当前口语 / 学术风格的英文表达＋中文讲解。
- 英文 → 同风格英文改写＋中文讲解。
- 原生编辑区使用 NSTextView，由苹果输入系统处理候选词、组合输入和英文键盘。
- 输入源与切换键由你的 macOS 设置管理，句外不拦截 Caps Lock、地球键、Control–空格或空格选词。

## 日常应用中的使用

运行句外后，在支持系统服务的应用里选中文字，从应用菜单的“服务”中选择“使用句外处理”。结果准备好后，在菜单栏点击“句外 ·”查看、复制，并自行粘贴。系统服务不要求句外监听全局键盘。

也可以授予辅助功能权限后，在菜单栏尝试“读取当前应用选中文字”。部分应用不会暴露标准选区，或打开菜单栏后改变焦点，此时使用系统服务或粘贴入口。

设置中可以单独开启**实验性自动检测**，当前仅针对备忘录和文本编辑的标准文本框：句末、光标在末尾、内容稳定后处理。每次启动默认关闭。不会主动弹出浮窗，不自动替换或发送外部文字。检测内容不超过 2000 字；不逐词翻译。辅助功能接口未必能识别所有输入组合状态，自动检测不是已验证功能。

**重要边界：保留苹果输入法时，助手不能假定可向所有应用的输入框插入独立的灰字提示。** 目前真正框内灰字只在句外原生编辑区实现；跨应用提供服务 / 选区处理和菜单栏结果。外部替换暂不开放。

## 在 Mac 上构建

目标 macOS 13+；需包含对应 SDK 的 Xcode / Command Line Tools。Intel 与 Apple Silicon 各自原生构建。

```sh
git clone https://github.com/pengruoxin/Aside.git
cd Aside
bash scripts/build-macos.sh
open dist/Aside.app
```

脚本先运行 `swift test`，再构建 `.app` 并做本机临时签名。可用 Xcode 打开 `Package.swift` 查看代码；菜单栏服务的完整测试请运行打包后的 `.app`。

CI 配置在 `macos-15`（Apple Silicon）和 `macos-15-intel` 上分别执行测试、构建并生成 zip。只有上传代码且 Actions 实际成功后才会有可下载产物。当前未执行，支持 macOS 13 是部署目标，不是已完成的兼容性认证。

这些产物没有 Developer ID 签名和公证，不能当作公开发布安装包。正式分发前需要签名、公证和真实设备验收。

## 配置真实模型

此里程碑接本机 [Ollama](https://docs.ollama.com/quickstart) 的 `/api/generate` 服务，模型须自行安装。默认不指定或下载模型。

1. 在 Mac 安装并启动 Ollama，安装你选定的中英双语模型。
2. 在句外“偏好设置”中填写完整模型名，与本机 `ollama list` 一致。
3. 连接固定本机地址 `http://localhost:11434`；不支持远程地址，不需要 API Key。
4. 输入中文或英文，使用句末自动触发或“处理整段”。点击灰字查看讲解。模型未配置时会明确提示，不用示例假装真实翻译。

服务使用非流式 JSON 输出并校验结果；模型质量、速度、资源需求由你选择的模型决定。原文、改写和讲解不写入客户端历史或正文日志；服务自身的数据处理规则需查看其配置。

## 隐私与安全

- 手动服务只处理用户主动选中的文本。实验自动模式会读取当前允许应用的文本控件；只将通过长度和句界检查的内容交给本机模型。
- 无全局按键监听；无模拟退格；无自动发送；无任意外部正文写入。
- 不读取安全密码控件，自动模式仅有两个应用在允许列表；权限撤销或读取失败时停止。
- 暂停、编辑、改变风格或切换来源应用会使旧请求失效。
- 本机模型仍可能误译，请在使用前检查。学术风格提示词要求保留原文事实与不确定性。
